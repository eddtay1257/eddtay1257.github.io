What Is HTML?

HTML stands for HyperText Markup Language. It organizes text, images, links, lists, and other content on a webpage.

Basic HTML Structure

An HTML document starts with a doctype declaration. The html element contains the whole page. The head contains page information, and the body contains the content visitors see.

Common HTML Elements

Element Purpose
<h1> Creates a main heading.
<p> Creates a paragraph.
<a> Creates a hyperlink.
<img> Displays an image.
<ul> and <li> Create a list and its items.
<table> Organizes information into rows and columns.

HTML Attributes

Attributes provide extra information about HTML elements. The src attribute tells an image where its file is located. The alt attribute describes the image.

Semantic HTML

Semantic HTML elements describe the purpose of different parts of a webpage. Examples include header, nav, main, section, and footer. They help organize the page.

HTML and CSS

HTML creates the structure of a webpage. CSS controls its appearance, including colors, fonts, spacing, and layout.

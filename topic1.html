What Is HTML?

HTML stands for HyperText Markup Language. It is used to organize text, images, links, lists, tables, and other content on a webpage.

Basic HTML Structure

An HTML document begins with a doctype declaration. The html element contains the entire page. The head section contains page information while the body contains the content that visitors see. 

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello</h1>
    <p>This is a webpage.</p>
</body>
</html>

Common HTML Elements

Element Purpose
<h1> Creates a main heading.
<p> Creates a paragraph.
<a> Creates a hyperlink.
<img> Displays an image.
<ul> and <li> Create an unordered list and its items.
<table> Displays information in rows and columns.

HTML Attributes

Attributes provide additional information about HTML elements. For example, an image can use the src attribute to identify its file and the alt attribute to describe the image. 

<img src="photo.jpg" alt="A photograph">

Semantic HTML

Semantic HTML elements describe the purpose of different parts of a webpage. Examples include header, nav, main, section, and footer. These elements help organize content and make the page easier to understand.

HTML and CSS

HTML provides the structure of a webpage. CSS controls the appearance, including colors, fonts, spacing, borders, and layout.

About the Student

My name is Eddie, and I am an Information Technology student at Kennesaw State University. I am interested in learning how websites are built and how HTML and CSS work together to create webpages.

About the Project

This website was created for IT 3203 Web Development Project Milestone #1. Its purpose is to introduce HTML and explain basic webpage structure and design.

The design is inspired by the Photolio template from W3Schools. The website uses basic HTML, one CSS file, hyperlinks, and a simple grid layout.

What I Am Practicing

  • Organizing content with HTML elements.
  • Creating links between webpages.
  • Styling webpages with CSS.
  • Using CSS selectors and grid layouts.
  • Making webpages easier to use on smaller screens.

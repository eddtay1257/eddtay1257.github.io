Seven Key Concepts

1. HTML

A markup language used to structure webpage content.

2. CSS

A stylesheet language used to control the appearance and layout of webpages.

3. Element

A part of a webpage, such as a heading, paragraph, link, or image.

4. Attribute

Extra information added to an HTML element, such as an image's source or alternative text.

5. Selector

A CSS pattern used to choose which HTML elements receive a style.

6. Semantic HTML

HTML elements that describe the purpose of content, such as main, nav, and footer.

7. Responsive Design

A design approach that helps webpages adjust to different screen sizes.

Three Types of CSS Selectors

Selector Type Example Purpose
Element selector body Styles all body elements.
Class selector .card Styles elements that use class="card".
ID selector #page-note Styles the element with id="page-note".

CSS Grid

CSS Grid organizes content into rows and columns. In this website, the grid displays related topics in separate cards. The layout changes to one column on smaller screens.

Hyperlinks

Hyperlinks connect webpages. The navigation menu uses the HTML anchor element to let visitors move between all six pages.
